**Estimating stage-specific breeding survival of albatrosses via remote time-lapse imagery**

This repository contains the data and R code supporting the manuscript “Estimating stage-specific breeding survival of albatrosses via remote time-lapse imagery.”

The study uses observations extracted from time-lapse images to estimate stage-specific survival and breeding success for Salvin’s Albatross (Thalassarche salvini) breeding on Proclamation Island in the Bounty Islands, New Zealand.

**Repository contents**

_Image_data.csv_

Contains the observations extracted from the Extensible Metadata Platform (XMP) tags embedded in the time-lapse images. These observations describe the recorded contents and developmental stage of each monitored nest through time.

_Survival_martix_and_jags_model.r_

Imports and cleans Image_data.csv, structures the encounter histories and other data required for analysis, and runs the hierarchical Bayesian state-space model in JAGS. The script saves the retained posterior samples as a draws data frame.

The complete posterior-draw dataset is not included in this repository because of its file size but is available from the corresponding author on reasonable request.

_Results_and_plots.r_

Uses the posterior draws generated by Survival_martix_and_jags_model.r to:

Summarise the posterior distributions.
Calculate stage-specific survival and overall breeding success.
Produce two of the figures presented in the manuscript.

**Running the analysis**

The scripts should be run in the following order:

_Survival_martix_and_jags_model.r
Results_and_plots.r_

Download or clone the complete repository and set the repository folder as the R working directory before running the scripts. The first script requires a working installation of JAGS and the R packages identified at the beginning of the script.

Running the complete Bayesian model may take considerable time. The resulting posterior draws must be available in the working environment before running Results_and_plots.r.
